# 接入与冻结

确认 paper.md 为 UTF-8，列出已有文献、数据、统计输出和作者关心的检查范围。读取 CURRENT；损坏时先 verify/recover。用 context --output 获取正文、旧选择、历史变体、语义记录和差异。

## 稿件只有 PDF、Word 或 LaTeX 时

工具只读 Markdown。转换是 Agent 的工作，转换结果就是之后被检查的正文，因此：

- 用可复现的工具转换（如 pymupdf4llm、pandoc），保留转换命令和原文件 SHA-256，写进阶段性输出。
- 逐页对照原文件抽查：页眉页脚、页码、脚注、跨页断开的段落、浮动图表把段落截断的位置。被截断的段落要接回去，否则句子边界和数值位置都会错。
- 图中文字（坐标轴、图例）通常删除；图注保留。公式写成 `$$…$$` 块；结果表格保留为 Markdown 表格，数字要逐格对照原件，PDF 抽取常把列错位。
- 作者占位符（如 `[To be completed]`）原样保留，之后登记为 non-claim，不要补写。
- 转换偏差不是论文错误。报告里把“转换产生的问题”和“稿件本身的问题”分开。

输出：本轮检查范围、来源缺口、正文来源与转换记录，以及哈希匹配的上下文。此阶段不推断证据已通过。
